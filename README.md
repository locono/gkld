# 公考雷达 gkld.net

> **网址：gkld.net**

一个纯静态、零依赖的单页导航站，用于集中展示考公 / 考研课程目录、笔记网盘群与课程更新日志入口。

整站只有 **一个 `index.html` 文件**，可直接拖拽部署上线。

---

## 目录结构

```
公考雷达/
└── index.html      # 全部内容（HTML + CSS + JS 内联，无外部依赖）
```

没有构建步骤、没有 npm 依赖、没有运行时框架，用浏览器直接双击打开也能正常工作。

---

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 顶部导航 | 左侧雷达 LOGO +「公考雷达」；中间四个文字导航，均以新窗口打开对应页面；右侧实时显示当天日期与星期 |
| 主视觉 | 超大渐变标题 + 醒目展示的 `gkld.net`（仅展示，非链接）；右侧为纯 CSS 实现的雷达扫描动画 |
| 目录导航卡片 | 考公课程目录、考研课程目录、免费笔记网盘群、课程更新日志四张卡片，整卡可点、新窗口打开，带悬停光晕与标签云 |
| 悬浮按钮 | 右下角圆形按钮，滚动超过 320px 淡入，点击平滑返回顶部 |
| 页尾联系方式 | 考公 QQ `1620668378`、考研 QQ `1024687680`，点击即复制，弹出「QQ已复制」提示 |
| 页尾网址 | 大号 `gkld.net` 渐变展示（非链接） |

### 交互细节

- **日期**：由 JS 从本地时间生成，无需后端。
- **QQ 复制**：优先使用 `navigator.clipboard`，`file://` 或非安全上下文下自动降级为 `document.execCommand('copy')`，保证本地预览也能复制成功。
- **滚动入场**：使用 `IntersectionObserver` 做卡片入场动画，不支持的浏览器自动跳过动画，不会白屏。
- **动效降级**：系统开启「减弱动效」时，全部动画与过渡自动关闭。

### 响应式断点

| 断点 | 变化 |
| --- | --- |
| ≥ 980px | 双列 Hero（文字 + 雷达图），卡片两列 |
| < 980px | Hero 转单列，雷达图移到标题上方 |
| < 860px | 卡片区、页尾 QQ 卡转为单列 |
| < 720px | 导航栏换行，日期移到右上角，导航条可横向滑动 |

字号与间距统一使用 `clamp()` 流式缩放，从窄屏手机到宽屏 PC 都能自适应。

## 常见修改

### 修改导航或卡片链接

搜索 `https://docs.qq.com/doc/`，把对应 `<a>` 的 `href` 换成新地址即可。导航栏在 `<nav class="nav-links">` 内，内容卡片在 `<div class="grid">` 内。

### 修改 QQ 号码

搜索 `data-copy=`，页尾两个按钮分别写 `data-copy="1620668378"` 与 `data-copy="1024687680"`，改数字即可，复制逻辑不用动。

### 修改主题色

集中在 CSS 顶部的 `:root` 变量里：

```css
--blue:#2f6bff;    /* 主色 */
--cyan:#12c2e9;    /* 辅助色 */
--violet:#7b5cff;  /* 点缀色 */
--amber:#ff9f1c;   /* 强调色 */
--mint:#12b981;    /* 成功色 */
```

每张卡片的配色由自身行内的 `--c1` / `--c2` 两个变量控制，改这两个值即可换渐变。

### 替换 LOGO

顶部导航的 LOGO 是纯 CSS 画出来的（`.logo` 类），favicon 是 `<head>` 里内联的 SVG data URI，均可直接替换成 `<img>` 或新的 SVG 代码。
